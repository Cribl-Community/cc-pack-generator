# Zeek TSV samples (bro_*)

The `bro_*` directories in this folder hold lines copied verbatim from
[brimdata/zed-sample-data](https://github.com/brimdata/zed-sample-data) at commit `8da0758e1ee1a8f94895d640a7646fd2c27ca803`,
directory `zeek-default/` (Zeek v6.2.0, default configuration). Each file keeps the
log's Zeek header lines, then a subset of its data lines. Nothing inside a line was changed.
